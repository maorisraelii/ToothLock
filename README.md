# 🪥 ToothLock - אפליקציית מעקב צחצוח ומניעת שינה ללא צחצוח

אפליקציית אנדרואיד ייעודית שנועדה לפתור את הבעיה של הירדמות ללא צחצוח שיניים והתעוררות באמצע הלילה.

## ✨ תכונות מרכזיות
1. **ווידג'ט מסך הבית (Home Screen Widget):** סימון מהיר בקליק אחד ("צחצחתי" / "לא צחצחתי") ישירות ממסך הבית ללא צורך בפתיחת האפליקציה.
2. **זיהוי חיבור לשעון סמסונג (Galaxy Watch / Wear OS):** בדיקה אקטיבית האם השעון מחובר לטלפון.
3. **זיהוי מצב שינה (Sleep Mode / Bedtime Mode):** זיהוי כניסה למצב שינה (כשהמסך של שעון סמסונג מחשיך ונכנס ל-DND).
4. **התראת חירום רוטטת לשעון ולטלפון:** התראה בקטגוריית `CATEGORY_ALARM` שעוקפת מצב שינה ומרעידה את השעון כדי להעיר אותך בזמן.
5. **כפתורי פעולה ישירות מהשעון:** כפתור "צחצחתי עכשיו! 🪥" או "נודניק 10 דק'" ישירות על מסך השעון.
6. **מונה רצף ימים (Streak):** מעקב אחרי מספר הימים הרצופים שבהם צחצחת לפני שעת היעד.
7. **עדכונים מהאוויר (In-App OTA Updates):** האפליקציה בודקת אוטומטית אם יש גרסה חדשה ב-GitHub ומציגה חלונית לעדכון בלחיצת כפתור ישירות מתוך האפליקציה, ללא צורך בהורדה ידנית דרך דפדפן!

## 🚀 הורדה והתקנה קלה (ללא צורך בסביבת פיתוח במחשב!)

### דרך 1: הורדה ישירה מדף ה-Releases ב-GitHub
* היכנס לדף ה-**Releases** ב-GitHub:
  👉 [ToothLock GitHub Releases](https://github.com/maorisraelii/ToothLock/releases)
* הורד את הקובץ `ToothLock.apk` ישירות לטלפון הגלקסי שלך והתקן אותו.

---

### דרך 2: יצירת APK והתקנה אוטומטית עם הסקריפט (ב-VS Code)
פתח טרמינל בתיקיית הפרויקט והרץ:
```powershell
.\build_apk.ps1
```
הסקריפט מאפשר לך:
1. **לבנות בענן (GitHub Actions)** ולהוריד את ה-APK המעודכן ביותר מיידית למחשב.
2. **אם הטלפון מחובר בכבל USB עם ADB** – להתקין אותו ישירות על המכשיר בלחיצת מקש אחת!

## 📁 מבנה הפרויקט

```
ToothLock/
├── app/
│   ├── src/main/java/com/toothlock/app/
│   │   ├── MainActivity.kt               # מסך ראשי: הגדרת שעה, סטטוס שעון ובדיקת התראה
│   │   ├── ToothWidgetProvider.kt        # לוגיקת הווידג'ט במסך הבית והחלפת צבעים/מצב
│   │   ├── ToothPreferences.kt           # שמירת סטטוס צחצוח יומי ורצף ימים (Streak)
│   │   ├── ToothCheckWorker.kt           # בדיקת רקע בשעת היעד (WorkManager)
│   │   ├── WatchAndSleepDetector.kt      # זיהוי שעון סמסונג וזיהוי מצב שינה
│   │   ├── NotificationHelper.kt         # יצירת התראת אזעקה רוטטת לשעון
│   │   ├── NotificationActionReceiver.kt # קבלת לחיצות מכפתורי ההתראה בשעון
│   │   └── BootReceiver.kt               # שחזור הבדיקה היומית בהפעלת הטלפון
│   └── src/main/res/
│       ├── layout/activity_main.xml      # ממשק האפליקציה הראשית
│       ├── layout/widget_tooth.xml        # ממשק הווידג'ט במסך הבית
│       └── xml/tooth_widget_info.xml     # הגדרות הווידג'ט למערכת אנדרואיד
├── .github/workflows/
│   └── build_apk.yml                     # בנייה אוטומטית של APK בענן ופרסום Release
├── .vscode/
│   ├── tasks.json                        # משימות קימפול והרצה מתוך VS Code
│   └── settings.json
├── build_apk.ps1                         # סקריפט אוטומטי ליצירת APK והתקנה
├── PROJECT_MEMORY.md                     # תיעוד ארכיטקטורה מלא
└── README.md
```
